# 原稿の記法

原稿（`.txt`）に書ける記法の一覧と、それぞれが出力ごとにどう組まれるか。プレビューと CLI（`novel`）のどの出力も同じ原稿を読む。

出力の呼び方は `novel.json` の `"outputs"` の形式と同じにしている。

| 呼び方 | 中身 |
| --- | --- |
| プレビュー | 拡張のプレビュー。日本語の原稿は pdf と、英語の原稿は pdf-en と同じに組む |
| pdf | 字数×行数の縦書き（横書き）の PDF |
| novel-pdf | 文庫本の見開きの PDF |
| epub | 電子書籍 |
| docx | 縦書きの Word 文書 |
| rtf | 日本語の RTF（ＭＳ明朝） |
| rtf-en | 英語投稿用の RTF（Shunn 形式） |
| pdf-en | 英語のペーパーバック風の PDF |
| split / merge | 章ごとの txt / 1本にまとめた txt |

行の頭に書く記法（`#`・`Lead:` など）は、行の1文字目から書く。前に空白があると本文になる。`Lead:` などの英字は大文字・小文字も、コロンが半角であることもこのとおりに書く。

## 章見出し `#`

```
#
# 朝の駅
```

行頭の `#` の後ろに空白を空けて題を書いた行が章の見出しになる。題のない章は `#` だけの行にする。1つのファイルに1つ、本文の前に書く。

- `#` は全角の `＃` でも、後ろの空白は全角でもよい。`#タグ` のように空白を空けない行や、`## 題` は本文になる
- 以前の書き方の `【】` も同じに読む。`【】` は `#`、`【朝の駅】` は `# 朝の駅` と同じ。行頭が `【` で始まり `】` で閉じる行が見出しになる
- 見出しで始まるファイル（空行と `Memo:` などの行は飛ばして、最初の行が見出し）から新しい章になる。見出しで始まらないファイルは前の章の続きで、ファイルの継ぎ目に場面区切りの記号を入れる
- 本文の途中の行でも、見出しの書き方の行は見出しになる。本文で行頭に `# ` や `【】` を使いたいときは、前に全角空白を入れる

| 出力 | 組み方 |
| --- | --- |
| プレビュー・pdf・docx | 章番号を振る。`#` は `【1】`、`# 朝の駅` は `【1　朝の駅】` になる。部に分けたとき（`novel.json` の `"parts"`）は「部-章」（部に章が1つなら「部」）。章ごとに改ページする（部に分けたときは部の頭でだけ改ページする） |
| novel-pdf・epub | 通しの章番号を振り、章ごとに改ページする。epub は目次にも章題を出す |
| rtf | `【朝の駅】` の形で太字で出し、前で改ページする。番号は振らない |
| rtf-en | 改ページして、中央寄せの「Chapter One」と章題の章扉にする |
| pdf-en | 章ヘッダに「One」などの章番号と章題を出す。部に分けたときは部扉（Part One）を入れ、章番号を部ごとに振り直す。章が1つだけで章題も `Subhead:` も無ければ章ヘッダを出さない |
| split | 章ごとのファイルに分け、見出しに番号を振る。部に分けたときは部ごとのファイルにし、番号を「部-章」にする |
| merge | 見出しに番号を振る。部に分けたときは「部-章」 |

章ごとの改ページと、見出しと本文の間の空行は、出力ごとに選べる（プレビューはページ設定のタブの「章」の欄で選ぶ）。

| 項目 | 効く出力 | 既定 |
| --- | --- | --- |
| `"chapterBreak": false` | pdf・pdf-en・novel-pdf・epub・rtf・rtf-en・docx | 章ごとに改ページする。false なら改ページせず、前の章との間を1行空けて続ける（pdf-en は章ヘッダの上に空きを取り、epub は全章を1つのファイルにする。部に分けたときの部の頭では改ページする） |
| `"blankAfterHeading": true` | pdf・novel-pdf・epub・rtf・docx・merge | 見出しの後に空行を補わない（原稿に書いた空行はそのまま組む）。true なら見出し（とエピグラフ）の後に空行を1行補い、原稿に空行があれば二重にしない |

pdf-en と rtf-en は章ヘッダ・章扉の後に常に空きを取り、split は章ごとのファイルで見出しの後に常に空行を置く。

英語の原稿では、以前の書き方で `【The Letter】Dear Anna,` のように `】` の後ろに本文を続けて書ける（pdf-en・rtf-en では後ろが本文の段落になる）。

## 行の頭に書く記法

### `Memo:`

```
Memo: ここは後で直す
```

どの出力にも出さない。字数にも数えない。

### `Lead:` / `Source:`

```
Lead: 国境の長いトンネルを抜けると雪国であった。
Source: 川端康成『雪国』

#
```

`Lead:` は章の頭に本文と別に組む文（エピグラフなど）。`Source:` はその出典で、`Lead:` の直後（空行を挟んでもよい）に書く。前が `Lead:` でない `Source:` は使わない。`Lead:` は見出しの前に書いても後ろに書いてもよく、どちらでも見出しの後ろに組む。複数書ける。

| 出力 | 組み方 |
| --- | --- |
| プレビュー・pdf・novel-pdf | 見出しの後ろに地付き（縦書きでは下揃え）で組み、出典は `——出典` の行にする。文と出典を合わせて1行に収まるなら1行に続ける |
| epub | 見出しの後ろに、本文より小さく薄い字で組む |
| docx | 見出しの後ろに下揃えで組む（1行の字数で折り返す） |
| rtf・rtf-en | 右寄せ |
| pdf-en | 章ヘッダの下に、イタリックの右寄せで組む。出典は `—出典` |
| split | `Lead:` / `Source:` の行のまま、見出しの後ろに置く |
| merge | 記法を外し、見出しの後ろに `文——出典` の1行にする |

### `Subhead:`

```
#
Subhead: 佐倉の章
```

章見出しに添える短い文（視点人物名など）。章を始めるファイルに書く。複数書ける。

| 出力 | 組み方 |
| --- | --- |
| プレビュー・pdf・novel-pdf・epub・docx・rtf・split・merge | ファイルで最初の見出しの後ろに、全角空白で区切って続ける（`【1】　佐倉の章`） |
| rtf-en | 章扉の章題の下に中央寄せ |
| pdf-en | 章ヘッダの章題の下 |

## 場面区切りと記号だけの行

```
*
***
* * *
```

`*`（全角の `＊` も可）だけの行（間の空白は問わない）は場面区切り。原稿ではどれで書いても同じで、出力ごとの記号に変える。

| 出力 | 組む記号 |
| --- | --- |
| プレビュー・pdf・novel-pdf・epub・docx・rtf・split・merge | `＊`。作品の `novel.json` の `"sceneBreak"`（出力ごとの `"sceneBreak"`）で変えられる |
| pdf-en・英語の原稿のプレビュー | `* * *`。`"english"` の `"sceneBreak"` で変えられる |
| rtf-en | `#` |

`◇◇◇`・`■■■`・`※`・`>>>` のように、`◇◆□■○●◎※>＞` だけの行は飾りの区切りで、書いた記号のまま場面区切りと同じ位置に組む（rtf-en だけは `#` の場面区切りにする。pdf-en は記号の間を少し空ける）。

```
*: ☆　☆　☆
＊：〜〜〜
*:
```

ほかの記号（`☆`・`〜` や、記号と文字の組み合わせ）を区切りにしたいときは、行頭に `*:` を付けて後ろに記号を書く（`*` もコロンも全角でよい）。書いた記号のまま、飾りの区切りと同じに組む。記号を書かない `*:` は `*` の場面区切りと同じ。`*:` の行は本文として読まないので、区切りの記号を変えても、ここが区切りだという印は残る。

区切りの行は行の中央に置く。`novel.json` の `"sceneBreakIndent"` に字数を書くと、中央ではなく行頭からその字数だけ下げて置く（split / merge は指定が無ければ行頭）。中央は（1行の字数 − 記号の字数）が奇数だとマス目から半字ずれるので、マス目に揃えたいときに使う。

英語の出力では、空行も区切りとして扱う。pdf-en では空行が場面の小休止の行アキになり、rtf-en では空行も `#` の場面区切りになる。pdf-en と英語の原稿のプレビューは `---` だけの行（翻訳作業用の罫線）を出さない。

## 行の中の記法

| 記法 | 書き方 |
| --- | --- |
| ルビ | `\|漢字《かんじ》`（`\|` は全角の `｜` でもよい） |
| 傍点 | `《《強調》》` |
| イタリック | `*text*` |
| 横倒し | `<<text>>` |

ルビ・傍点はカクヨム・小説家になろうと同じ書き方。ルビは `漢字《かんじ》` のように縦棒を省くと、`《` の直前に続く漢字が親文字になる。親文字にかなが混じるときや、漢字の途中から振るときは縦棒を付ける。エディタで右クリックの「ルビを振る」（`Ctrl+Alt+R` / `Cmd+Alt+R`）・「傍点を打つ」でも書ける。

| 出力 | ルビ | 傍点 | イタリック | 横倒し |
| --- | --- | --- | --- | --- |
| プレビュー・pdf・novel-pdf | 親文字の字数に合わせて配置する（長いルビは前後のかなにはみ出させ、それでも余れば親文字の字間を空ける） | 1字ずつ点を打つ（約物・空白には打たない） | 対応しない（`*` のまま出る） | 縦書きで中身を横に倒して組む |
| epub | ルビ | 圏点 | 対応しない（`*` のまま出る） | 縦書きで中身を横に倒して組む |
| docx | Word のルビ | Word の傍点 | 斜体 | 中身を半角のまま出す（Word の縦書きで横に倒れる） |
| rtf | Word の EQ フィールド。出力の `"rubyParens"` で `漢字（かんじ）` の括弧書き | 傍点（`\accdot`） | 斜体 | 中身だけ出す |
| rtf-en | 同上 | 同上 | 斜体 | 中身だけ出す |
| pdf-en | 対応しない（記法のまま出る） | 文字の上に点 | 斜体 | 対応しない（記法のまま出る） |
| split | 記法のまま | 記法のまま | 記法のまま | 記法のまま |
| merge | 記法のまま。`"rubyParens"` で `漢字（かんじ）` の括弧書きにし、ほかの記法は外して中身だけ残す | 同左 | 同左 | 同左 |

横倒しの中にもルビを書ける。

### 縦書きでの自動の組み

縦書きの出力（プレビュー・pdf・novel-pdf・epub）では、記法を書かなくても次のように組む。

- 1〜2桁の数字と `!?` `!!` などの2字は縦中横（3桁以上の数字は1字ずつ縦に並べる）
- 半角の英字は1字ずつ縦に立てる（横に倒したいときは `<<>>` で囲む）
- `II`〜`XII` のローマ数字は1字のローマ数字にして立てる

## 青空文庫の注記

[青空文庫の注記](https://www.aozora.gr.jp/annotation/)のうち、次のものを読む。

| 注記 | 書き方 |
| --- | --- |
| ルビ | `｜親文字《るび》`・`漢字《かんじ》` |
| 傍点 | `X［＃「X」に傍点］`・`［＃傍点］X［＃傍点終わり］`（白ゴマ・丸などの種類は問わず、どれも傍点にする） |
| 左ルビ | `X［＃「X」の左に「Y」のルビ］`（縦書きは親文字の左、横書きは下に付ける） |
| 傍線 | `X［＃「X」に傍線］`・`［＃傍線］X［＃傍線終わり］`（二重傍線・鎖線・破線・波線も。縦書きは字の右、横書きは下に引く） |
| 太字 | `X［＃「X」は太字］`・`［＃太字］X［＃太字終わり］` |
| 斜体 | `X［＃「X」は斜体］`・`［＃斜体］X［＃斜体終わり］` |
| 縦中横 | `X［＃「X」は縦中横］`・`［＃縦中横］X［＃縦中横終わり］` |
| 見出し | `X［＃「X」は大見出し］`・`［＃大見出し］X［＃大見出し終わり］`（中見出し・小見出しも。行全体） |
| 改ページ | `［＃改ページ］`（改丁・改見開き・改段も改ページにする） |
| 字下げ | 行頭の `［＃３字下げ］`、`［＃ここから２字下げ］`〜`［＃ここで字下げ終わり］` |
| 地付き・地から上げ | 行頭の `［＃地付き］`・`［＃地から２字上げ］` |
| 挿絵 | `［＃挿絵（images/fig1.png）入る］`（1行に1つ。下の「挿絵」） |

字数は半角でも全角でも書ける。前方参照の注記（`［＃「X」に傍点］`）は、直前の文字が `X` で終わっているときだけ効く。

これ以外の注記（「の左に傍線」・外字の説明など）は注記だけを捨て、本文はそのまま残す。ルビを振った語に付けた傍線・左ルビ（`漢字《かんじ》［＃「漢字」に傍線］`）も、傍点と同じく対象の文字列と一致しないので捨てる。

| 出力 | 組み方 |
| --- | --- |
| プレビュー・pdf・novel-pdf・epub | すべて組む。見出しは本文と同じ大きさのゴシック体の太字（章見出し `#` とは別の、本文の中の見出し）。鎖線は点線で代える |
| docx | すべて組む。見出しは太字。左ルビは親文字だけ出し、傍線の中のルビは外す |
| rtf | ルビ・傍点・太字・斜体・改ページは組む。傍線は種類ごとの下線、左ルビは親文字の下のルビにする。見出しは太字。縦中横は中身だけ出し、字下げ・地付きは効かない |
| rtf-en | 同上 |
| pdf-en | 傍点・太字・斜体は組む。傍線・縦中横は中身だけ、左ルビは親文字だけ出す。ルビは対応しない。見出しは本文の段落になり、改ページ・字下げ・地付きは効かない |
| split | 注記のまま書き出す |
| merge | 注記のまま書き出す。`"rubyParens"` ではルビを括弧書きにし、ほかの注記は外す |

### 挿絵

```
［＃挿絵（images/fig1.png）入る］
［＃「駅のホーム」のキャプション付きの図（images/fig1.png、横600×縦900）入る］
```

`（）` の中に画像のファイル名を、その原稿の `.txt` のディレクトリからのパスで書く。画像は png・jpg・gif・svg・webp。`（）` の前の説明は何を書いてもよく、`「X」のキャプション付きの…` なら X を、それ以外は説明をそのまま画像の代替テキストにする（画面には出さない）。ファイル名の後ろの `、横N×縦M` などは読まない。行の中に書いた挿絵の注記は読まない。

| 出力 | 組み方 |
| --- | --- |
| epub | 画像を EPUB に入れ、1ページに1枚、画面に収まる大きさで組む |
| novel-pdf | 1ページに1枚、版面に収まる大きさで組む |
| プレビュー・pdf・docx・rtf・rtf-en・pdf-en | 出さない（投稿用の原稿には挿絵を入れないため） |
| split・merge | 注記のまま書き出す |

epub・novel-pdf では、挿絵の注記の前後の空行は組まない。画像のファイルが無ければエラーにする。

## 梗概・人物紹介のファイル

原稿のディレクトリに置く、本文とは別のファイル。

- `synopsis.txt`: 梗概（あらすじ）
- `characters.txt`: 人物紹介

入力にディレクトリを渡したときは、そのディレクトリから探す。ファイルを渡したときは、最初のファイルと同じディレクトリから探す。

| 出力 | `synopsis.txt` | `characters.txt` |
| --- | --- | --- |
| pdf | 表紙の次に「梗概」の見出しを付けたページを入れる。出力の `"synopsisOnTitle"` で表紙のタイトルの下に載せ、`"synopsis": false` で入れない。`"coverless"` では梗概のページの頭にタイトル・著者名を出す | 梗概の次に「登場人物」の見出しを付けたページを入れる |
| docx | 表紙の次に「梗概」の見出しを付けて入れる。表紙と梗概にはページ番号を振らない。`"synopsis": false` で入れない | 使わない（本文にも入れない） |
| プレビュー・split | 使わない（本文にも入れない） | 使わない（本文にも入れない） |
| novel-pdf・epub・rtf・rtf-en・pdf-en | 使わない（本文にも入れない） | 本文のファイルとして読む |
| merge | 使わない（本文にも入れない） | 本文のファイルとして読む |

梗概・人物紹介の行は1行ずつ段落にし、空行は空行のまま組む。ルビ・傍点などの行の中の記法は本文と同じに組む。青空文庫の注記は読まないので、ルビは半角の `|` を付けて書く（全角の `｜` や縦棒を省いた書き方はルビにならない）。docx の梗概は `Memo:`・`Lead:`・`Source:`・`Subhead:` と章見出しの行を出さない（pdf ではそれらの行も出る）。

pdf の下読み用（出力の `"review"`）では、梗概・人物紹介をどちらも入れない。
